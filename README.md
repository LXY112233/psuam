# Please Stand Up And Move · PSUAM

一款 Windows 桌面走动提醒工具。支持提醒时刻、间隔、星期与时段，自定义弹窗位置，以及保存在本机的起身打卡统计。

## 使用

下载 [最新正式版本](https://github.com/LXY112233/psuam/releases/latest)，完整解压后运行 `走动提醒.exe`。请保留旁边的 `走动提醒.exe.config`，不要直接在压缩包内运行。

需要 Windows 10/11 和 .NET Framework 4.7.2 或更新版本；Windows 11 通常已包含所需运行环境。

关闭主窗口后仍在托盘运行；右键托盘图标可暂停提醒、测试通知或完全退出。

## 起身打卡

- 正式提醒中选择“我已起身”或“继续工作”，会保存本次选择。关闭、超时、稍后提醒等也会归入相应状态。
- 日视图按小时显示点图，周/月/年视图显示柱状图；周从星期一开始。
- 点击年份中的柱形进入月份，点击周/月中的柱形进入当天。
- 可以查看历史日期、回到今天，并导出当前时间范围的 CSV 明细。
- 一条记录始终按提醒出现的本地日期归档，跨午夜回应仍属于原提醒日。
- 预览通知不计入正式打卡。按钮选择不代表实际走动时长；软件不测量走动时长。

## 软件更新

默认更新仓库为 `LXY112233/psuam`，通过 GitHub Releases 获取正式版本。

客户端在本地时间每天 09:00 检查一次；如果当时未运行，当天稍后启动或从睡眠恢复后会补查。同一天重启不会重复自动请求。自动检查失败时当天不循环重试，可以在“软件更新”页手动重试。每日检查需要客户端正在运行，不会唤醒已关机的电脑。

发现新版本后，在下一次正式起立提醒中显示提示。预览提醒不显示升级提示，也不会自动安装。点击提示后，可查看版本说明并自行选择下载升级。软件更新页也支持随时手动检查。

安装前验证更新包 SHA-256、版本及压缩包路径，只替换程序和运行配置；安装目录保留旧文件备份。提醒配置和打卡记录不随程序文件替换。

数据位于 `%LOCALAPPDATA%\QingMoveReminder`：`settings.json` 为配置，`activity\yyyy-MM.jsonl` 为打卡记录，`update-state.json` 为更新检查状态。数据仅保存在本机；检查更新只向 GitHub 请求公开版本和安装包。

## 从源码构建

源码位于 `源码`。使用 Windows PowerShell：

```powershell
& '.\源码\build.ps1' -RunUiTests -RunVisualTests
```

使用 Windows 自带的 .NET Framework 编译器（C# 5），不依赖 Node.js 或 Python。源码包含本地数据、调度、更新包校验、失败恢复、交互和字体测试。测试生成的演示记录位于构建目录，不写入真实打卡数据。

## 发布新版本

1. 更新 `Program.cs` 的程序集版本，并在干净目录构建和测试。
2. 创建正式标签，例如 `v1.5.1`，安装包命名为 `PSUAM-windows-v1.5.1.zip`。
3. 压缩包中包含且仅包含一套 `走动提醒.exe` 和 `走动提醒.exe.config`，两者在同一目录；不要放入旧版或测试 EXE。
4. 上传 ZIP 及对应的 `PSUAM-windows-v1.5.1.zip.sha256` 到同一个正式 Release。校验文件格式为 `SHA256值  文件名`。
5. 发布为正式版本；草稿及预发布版不会被客户端自动采用。客户端不需要 GitHub 令牌。
